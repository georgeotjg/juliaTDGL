Tools

What a user touches: a terminal menu, a browser editor for shapes, the standard figures of a run, and 3D films of the vortex events.

The terminal menu

julia julia/scripts/tdgl_tui.jl
  • It lists the runs of both releases, live and archived, with their state, points, last current and verdict.
  • n launches a run of release 2.0 from any run file; two CPUs run the polarities in parallel.
  • s stops a run after its current point, and u resumes it to the bit.
  • l is a launch wizard (starting point, geometry, parameters, optional term) for release 1.2 or for the two-band model in 2.0.
  • g opens the shape editor, and w the films of a run; in the details of a release-2 run, h walks its down branch and l runs its M(H) loop, in the background.

Closing the menu does not stop a run.

The shape editor

A browser editor for three-dimensional shapes (julia julia/editor/server.jl, or key g of the menu). It saves the TOML file that a run reads with GEOM_MODE = "CUSTOM". Each voxel is a mesh node.

  • Figures (circle, rectangle, triangle, polygon, sphere, n-gon) can be drawn on any of the three views and go through the sample along that view's axis.
  • A figure can be kept, which writes the material outside it: a cable.
  • A figure can write an f, which makes a normal metal or a weak link; vacuum, which carves the sample; or another material.
  • A pencil paints any 3D pattern.
  • The checks show the mirror and rotation symmetries (a symmetric shape gives η = 0 exactly) and the faces where vortices enter.
  • Material names suggest the catalogue of release 2, and "Run file" drafts the run file of the shape: a [materials.name] table for each material (the catalogue file when the name is one), the mesh of the box, the shape, the insulating buffer when it has vacuum, and a ladder to edit.

What it draws is what the solver reads: the two were compared node by node, in a headless browser with real mouse events.

The figures of a run

julia --project=tdgl2 tdgl2/scripts/figures.jl RUNDIR

From the folder of any run (it can still be running) this draws:

  • the sheet of the ladders: crossings per line, |V|, the rung times and the current through the mid plane, with the brackets;
  • |Ψμ|² of every band on the three mid cuts, with the vortices and the supercurrent lines;
  • the share of the supercurrent each band carries, plane by plane along the sample;
  • REPORT.md, one page with what was run (the materials per region and the integrator included), every rung, the brackets and η.

3D films

julia --project=tdgl2 tdgl2/scripts/film.jl RUNDIR [+|-] [--J J] [--every DT] [--state FILE]

From the kept state of a rung, or from any state file, the film steps the state at its current. It records only around the moments that matter: the entry, the crossing and the exit of each vortex. It writes:

  • VTK files of every frame: |Ψμ|², the supercurrent, the field, the masks and the material of each node, for ParaView or any VTK reader;
  • a browser viewer (film.html) that turns and zooms with the mouse;
  • a GIF and a still frame.

Each material of the sample is tinted. A film of a continuous flow must be sampled well below its period 2π/V; the script warns when it is not, because a stroboscope can make a vortex appear to go back and forth.

Scripts and tools

toolwhat it does
