Publications and citing

The paper

J. A. Robles Calderón, Silent failure modes in three-dimensional two-band time-dependent Ginzburg–Landau simulations of geometric superconducting diodes, Zenodo (2026), doi:10.5281/zenodo.23163207.

It describes the solver of release 1.x and its measuring protocol: a crossing-count verdict rule, a gauge-invariant voltmeter, the bracketing of onsets. It also describes the failure modes those rules guard against: windows that bias an onset, a normal buffer that shunts the sample, counts read on a band without condensate. Tag v1.0.0 is the code it used; Config(:legacy) with mode = Strict() in release 1.2 reproduces its results to the digit.
