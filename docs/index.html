juliaTDGL

Three-dimensional multiband time-dependent Ginzburg–Landau solvers in Julia, written for the geometric superconducting diode effect.

N order parameters coupled by a Josephson matrix, a self-consistent vector potential, an applied field and a transport current, on mesoscopic samples of any shape. A run is a current ladder in each direction; its result is the onset of dissipation in each polarity and the diode efficiency, with the vortex dynamics that sets them.

Get startedThe modelSolver guide (PDF)The paper

What it solves

A sample whose shape breaks the mirror symmetry along the direction of vortex motion carries different critical currents Ic+ and |Ic−| in the two directions: a superconducting diode, with efficiency \( \eta = (I_c^+ - |I_c^-|)/(I_c^+ + |I_c^-|) \). The solvers compute that onset from the time-dependent Ginzburg–Landau equations in three dimensions: where vortices nucleate, how they cross, and how the current is shared between the bands of a multiband superconductor. Two-gap MgB2 motivated them; a material is a file of parameters, so another multiband material is a new file, not new code.

The model

Two formalisms: the two-band TDGL of release 1.2, and the N-band generalised TDGL of release 2.0, term by term.

The numerics

Link variables, the implicit curl-curl, stabilised stages for the stiff bands, the rotating frame, the noise.

Examples

One run file per option, each a single command, with the time it takes on a laptop core.

Tools

A terminal menu, a browser editor for 3D shapes, the standard figures of a run, 3D films of the vortices.

Two releases

Release 2.0 (tdgl2/), for new work

N bands, each with its own Kramer–Watts-Tobin relaxation (the charge imbalance at the contacts); normal fluids per band with a finite interband exchange; thermal noise; anisotropic bands; regions of different materials; samples carved in vacuum; open or bar boundaries for the self-field; the onset by the delay of the first phase slip. With its new terms off it reproduces release 1.2.

Release 1.2 (julia/), the published work

The two-band TDGL of the methods paper, with the scalar potential (Coulomb projection, Thomas–Fermi screening), a strict mode that reproduces release 1.0.0 to the digit, the terminal menu and the shape editor. Use it to reproduce the published results.

Quick start

Julia 1.13 or later; everything else is installed by the first command of each release.

git clone https://github.com/georgeotjg/juliaTDGL.git && cd juliaTDGL
julia --project=tdgl2 -e 'using Pkg; Pkg.instantiate()'
OPENBLAS_NUM_THREADS=1 julia --project=tdgl2 tdgl2/scripts/run.jl tdgl2/examples/wedge_k25.toml   # minutes

The first hour, from a run to its figures, a finer onset and a 3D film: tdgl2/TUTORIAL.md. More in Getting started.
